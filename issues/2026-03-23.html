1 SIGNAL 产业结构

Cursor-Kimi 事件全球发酵：从产品丑闻到中国 AI 技术实力的意外证明

Cursor 承认 Composer 2 底座为月之暗面 Kimi K2.5 的消息持续在全球科技圈发酵。日本 Gigazine、台湾科技新报、印度 Analytics India Magazine 等多国媒体跟进报道。焦点从最初的"信息披露缺失"逐步转向更深层的讨论：①模型供应链透明度——CTOs和投资者开始审视自己用的AI产品"引擎盖下"是什么；②中国模型的全球影响力——月之暗面不仅发了Attention Residuals论文，还通过商业授权进入了全球最热的编程工具；③定价权重构——Cursor用Kimi做底座后把价格打到竞品的1/5，直接施压OpenAI和Anthropic的编码产品定价。
为什么这件事重要

一周之内，月之暗面创造了两个"第一次"：论文层面，Attention Residuals让Karpathy和马斯克同时点赞；商业层面，Kimi K2.5成为500亿美元估值AI公司的技术底座。这两件事叠加在一起，构成了中国AI在2026年最强的"技术+商业"双重验证。对整个行业的启示是：基座模型的竞争已经从"谁的排名高"变成了"谁被全球产品选用"。

2 SIGNAL 产业结构

蔡崇信重磅发声：中国科技迎爆发期，电网投资+开源模型是两大驱动力

阿里巴巴主席蔡崇信在 Tech in Asia 专访中发表系统性判断：中国AI正在迎来爆发期，两大核心驱动力是——①大规模电网投资为AI算力提供了充足的能源保障；②开源模型的兴起显著降低了全球技术使用门槛。他特别指出：中国庞大的工业基础产生的海量数据是AI领域的重要竞争优势，"数据是新石油"在中国的工业语境下尤为成立。这番话紧随阿里财报中"五年千亿美元AI收入目标"和Qwen3.5登顶国产模型榜首之后。
为什么这件事重要

蔡崇信不是技术出身的CEO，他是投资人和战略家——当他说"爆发期"时，说的是商业回报而非技术进步。将他的判断与Hugging Face报告（中国模型占下载量41%）、Cursor选择Kimi做底座、阿里千亿美元目标放在一起看，一幅完整的图景浮现：中国AI正在从"技术追赶"进入"商业变现"阶段。

中关村论坛 AI 主题日将于 3/25-29 举办 · 朱松纯宣布"通通 3.0"本月发布

第三届中关村论坛人工智能主题日系列活动将于3月25日至29日在中关村国际创新中心举办，这是中国规格最高的AI产业盛会之一。与此同时，北京通用人工智能研究院院长、哈佛博士朱松纯在鄂州"荆楚科普大讲堂"上宣布："通通3.0"通用智能系统将于本月下旬发布，目标是为通用智能人装上"中国心"。此外，CSDN发布的数据显示：中国AI大模型周调用量达4.69万亿Token，连续两周领跑全球。

4 产品动态 新面孔

vLLM-Omni 发布：高性能多模态推理框架，vLLM 生态从纯文本走向多模态

vLLM 团队发布 vLLM-Omni——专为高效多模态模型推理设计的框架，迅速登上 GitHub Trending。vLLM 此前是纯文本大语言模型推理的事实标准，Omni 版本标志着其正式向多模态架构扩展。该框架优化了图像+文本+音频等复杂多模态模型的部署和推理速度，对于企业级多模态AI应用的落地具有重要意义。
为什么这件事重要

vLLM 是AI推理基础设施的关键组件——几乎每家部署大模型的公司都在用它。当vLLM走向多模态时，意味着企业级多模态AI应用（图文理解、视频分析、语音交互）的部署门槛正在大幅降低。这是从"模型多模态"到"基础设施多模态"的关键一步。

5 产品动态 新面孔

Claude HUD 监控插件登上 GitHub Trending：AI 驱动开发的"可观测性"成新需求

开发者 jarrodwatts 发布的 Claude HUD 插件登上 GitHub Trending，该工具提供实时监控 Claude Code 活动的仪表板：上下文窗口使用情况、活动工具状态、Agent行为追踪。这是第一个专门为AI编码Agent提供"可观测性（Observability）"的工具。同日，NousResearch 的 Hermes Agent 完成了一项里程碑：自主编写、排版、编辑并出版了一部完整的 7.9 万字小说。
为什么这件事重要

当AI Agent开始自主执行复杂任务时，"观察AI在做什么"变成了刚需。Claude HUD的流行说明：开发者对AI Agent的需求正在从"让它干活"进化到"让我看懂它在干什么"。而Hermes Agent自主写完一部7.9万字小说，则展示了AI Agent在创意领域的"端到端自主性"已达到令人惊讶的水平。

6 产业动态

Terafab 后续：Tesla-SpaceX-xAI 250 亿美元联合芯片厂引发行业分歧

Terafab 3月21日启动后，行业反馈两极分化。乐观派：Teslarati 称这是"AI算力自主权的里程碑"，Interesting Engineering 认为马斯克正在减少对外部供应链的依赖。怀疑派：Electrek 发表深度分析称"这是 Battery Day 的翻版——宏大承诺但交付时间表不现实"，指出2nm量产的技术难度远超马斯克的乐观预期。TechCrunch 同日报道了特斯拉与SpaceX合作芯片制造的更多细节，但行业观察人士对时间表可行性持谨慎态度。
为什么这件事重要

Electrek的"Battery Day翻版"类比非常精准——2020年Battery Day承诺的4680电池量产也拖了近3年。但即使Terafab的时间表打折，它的战略意义不变：马斯克系正在构建一个从芯片设计到制造的垂直闭环。值得注意的是：同一周，软银投5000亿美元建数据中心、贝索斯融1000亿美元做AI制造——全球顶级资本对AI算力基础设施的下注规模已经达到"国家级"。

8 研究

MIT 新方法识别"过度自信"的大模型幻觉 · 德勤报告：印度 AI 采用率领先全球

MIT 幻觉检测：麻省理工研究人员开发了一种新方法，专门用于识别大模型"过度自信"时产生的幻觉——不是模型说"我不知道"时的问题，而是模型非常确信地给出错误答案时的问题。这是幻觉检测领域的重要进展。德勤AI报告：印度在产品开发（62%）、战略运营（56%）和营销销售（55%）等领域的AI采用率均超全球平均，但同时面临显著的人才技能缺口。
为什么这件事重要

MIT的研究直击AI最棘手的问题——模型"自信地犯错"比"坦白不知道"更危险。在AI Agent时代，一个"过度自信"的Agent可能自主做出代价高昂的错误决策（参考本月Meta AI Agent失控事件）。印度的高采用率则提醒：AI的全球化竞争不只是中美之间，印度凭借庞大的IT人才基础和低成本优势正在快速崛起。
