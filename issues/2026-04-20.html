月之暗面发布并开源Kimi K2.6——万亿参数开源模型首次在核心benchmark上击败GPT-5.4和Claude Opus 4.6

4月20日晚间，月之暗面正式发布并开源Kimi K2.6。这是一个万亿参数MoE模型，256K上下文窗口，支持原生多模态（图片+视频）。最具突破性的能力：持续编码长达13小时、单次编写/修改超4000行代码、支持最多300个子Agent协同工作（4000步协调步骤）。在内部Kimi Code Bench上较K2.5提升约20%，在SWE-bench、HumanEval等多个基准上超越GPT-5.4和Claude Opus 4.6。SiliconANGLE和MarktechPost均做了深度报道。开源采用开放权重（open weights）模式。
⚡ 为什么重要：这是中国开源模型首次在顶级编码benchmark上全面击败美国闭源前沿模型。Cursor用K2.5做底座时还是"悄悄用"，K2.6直接在阳光下证明了自己。300子Agent集群的设计意味着月之暗面在"Agentic AI"赛道上已经不是跟随者。

阿里Qwen3.6-Max-Preview旗舰上线——智能体编程、世界知识、指令遵循三维全面超越Plus版

同日（4/20），阿里通义千问团队发布Qwen3.6-Max-Preview，定位为新一代千问旗舰的早期预览版。相比此前发布的Qwen3.6-Plus，在三个维度实现显著提升：智能体编程（agentic coding）、世界知识储备、指令遵循严格度。SWE-bench Pro表现突出，目前已在Qwen Studio开放交互对话，即将通过阿里云百炼API提供调用。ic.work分析认为，阿里真正想拿下的不是"跑分第一"，而是开发者API生态的入口。
⚡ 为什么重要：Kimi K2.6开源+Qwen3.6-Max闭源，国产模型同一天从两个方向对标美国闭源前沿。更值得注意的是，两家不约而同聚焦"agentic coding"——这不是巧合，是对下一个杀手级应用场景的共识判断。

Vercel确认遭AI工具供应链攻击——Context.ai OAuth漏洞打穿内部系统，客户数据被盗

4月19日披露、4月20日多家安全机构密集分析：Vercel确认一起严重安全事件。攻击链路：Context.ai（一个AI可观测性SaaS）员工账户被入侵→攻击者通过已授权的OAuth应用劫持了一名Vercel员工的Google Workspace账户→进入Vercel内部系统→窃取客户数据。TechCrunch、Trend Micro、OX Security、Cloud Security Alliance均发布了详细分析。被盗数据已在BreachForums（ShinyHunters）上出售。Vercel建议所有客户立即轮换环境变量。
⚡ 为什么重要：这是"AI SaaS作为企业攻击面"从理论变为现实的标志性事件。Cloud Security Alliance将其定性为"AI SaaS as Enterprise Attack Vector"的首个重大案例。当企业为了提升效率接入各种AI工具时，每个OAuth授权都可能成为攻击入口。
