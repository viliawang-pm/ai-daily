1 SIGNAL 产品动态

TechCrunch 独家：Cursor 承认 Composer 2 底座为月之暗面 Kimi K2.5——AI 模型供应链透明度成焦点

3月22日，TechCrunch 独家报道引爆全球科技圈：AI编程独角兽 Cursor 正式承认，其本周发布的前沿级编码模型 Composer 2 的底层基座是中国月之暗面（Moonshot AI）的 Kimi K2.5 模型。事件起因是一名X用户发现 Composer 2 的API响应中包含Kimi模型的签名。Cursor随后确认：通过 Fireworks AI 获取 Kimi K2.5 的推理服务，在此基础上进行了持续预训练（continuous pre-training）和强化学习。月之暗面也确认了这一商业授权合作。AlphaMatch.ai 发布深度分析称"Kimi K2.5 是引擎盖下的真正引擎"。
为什么这件事重要

这是2026年最具象征意义的AI产业事件之一。当全球估值最高的AI编程公司（谈判估值500亿美元）选择中国模型做底座时，它同时验证了三件事：①中国基座模型在编程领域已达世界一流水平；②AI产品的"模型供应链"透明度将成为新的合规要求——用户和投资者都想知道"引擎是什么"；③地缘政治因素正在进入AI商业决策——Cursor选择Kimi而非OpenAI/Anthropic，既是技术选择也是成本选择，但在五角大楼拿中国员工做安全论据的同一周，这个选择格外敏感。

2 产品动态

Midjourney V8 Alpha 发布：生成速度 5x 提升、原生 2K 分辨率、文本渲染大幅改善

Midjourney 推出 V8 Alpha 版本，核心升级包括：生成速度约5倍提升、支持原生2K分辨率、文本渲染质量显著改善。但伴随而来的是定价调整：顶级功能（如 `--hd` 模式）价格上涨4倍，且Alpha期间不提供Relax模式。这是Midjourney自V6以来最大的一次版本跃迁，也是AI图像生成领域在2026年的首个重大更新。
为什么这件事重要

V8的5x速度提升不仅是技术指标——它改变了创作者的工作流。当生成一张图从30秒变为6秒，AI图像生成就从"等结果"变成了"实时迭代"，体验质变。但4倍涨价也传递了一个清晰信号：Midjourney正在从"用户增长"转向"收入变现"，AI工具的免费午餐时代正在结束。同时，Microsoft同日发布的MAI-Image-2在Arena.ai排名第三，图像生成领域的竞争正在白热化。

3 产品动态

Google AI Studio 变身"全栈 Vibe Coding 平台"：Antigravity Agent + Firebase + 一键部署

Google 将 AI Studio 升级为完整的全栈开发环境，核心是 Antigravity Agent——一个能自主完成前后端开发的AI代理。支持原生 Firebase Auth/Firestore、Secrets Manager、Next.js/Shadcn/Three.js，以及一键部署。同日，Google 还宣布推出 Stitch——一个AI原生的"Vibe设计"工具，用于创建、迭代和协作高保真UI。此外，Google开始在Mac上测试原生Gemini AI桌面应用，直接与ChatGPT和Claude竞争。
为什么这件事重要

Google在一周内同时推出Vibe Coding（AI Studio + Antigravity）和Vibe Design（Stitch），加上原生桌面Gemini应用——这是Google对OpenAI"超级应用"战略的全面回应。"Vibe Coding"这个概念的成立意味着：开发者不再需要手写每一行代码，而是用自然语言描述意图，AI Agent完成从设计到部署的全流程。这对整个软件开发行业的影响不亚于当年IDE取代文本编辑器。

研究与开源生态
4 研究

Hugging Face 2026 春季开源报告：1300 万用户、200 万模型，中国模型占下载量 41%

Hugging Face 发布《2026 春季开源 AI 状态报告》，核心数据：1300万注册用户、200万+模型、50万+数据集。其中最引人注目的趋势是——中国模型占所有模型下载量的41%，这意味着全球开发者每下载10个AI模型，就有4个来自中国。此外，机器人相关数据集激增23倍，反映了具身智能赛道的爆发式增长。
为什么这件事重要

41%的下载占比是一个里程碑式的数字——中国AI从"跟跑"到"并跑"的证据不再是某个模型的排名，而是开发者用脚投票的结果。Qwen、DeepSeek、Kimi、MiniMax等模型的集体崛起，正在改变全球AI开源生态的重心。机器人数据集23倍增长则预示着：2026年下半年，具身智能将成为与大语言模型同等重要的赛道。

5 研究 新面孔

UC Berkeley M²RNN：矩阵值状态非线性 RNN，挑战 Transformer 在长上下文的统治地位

UC Berkeley 发布 M²RNN（Matrix-valued state Nonlinear RNN），这是一种具有矩阵值状态的新型非线性循环神经网络。实验显示：在 WikiText 上困惑度下降10个点，在长上下文任务上提升高达8个点。这是继 Mamba/RWKV 之后，又一个试图用非 Transformer 架构解决长序列建模问题的重要尝试。
为什么这件事重要

Transformer 的二次复杂度问题在百万Token时代越来越突出。M²RNN 提出的矩阵值状态机制，为"后Transformer时代"的架构探索提供了一个新方向。虽然距离替代Transformer还很远，但学术界对替代架构的密集探索（Mamba → RWKV → Attention Residuals → M²RNN）说明：Transformer可能不是终局。

6 产品动态

Microsoft MAI-Image-2 发布 · Adobe 接入 Kling AI 视频 · Perplexity 进军健康数据

Microsoft MAI-Image-2：微软内部文本生成图像模型，在 Arena.ai 排名第三，正集成到Copilot和Bing Image Creator中，直接与Midjourney和DALL·E竞争。Adobe × Kling：Adobe Firefly平台正式接入快手旗下Kling AI视频功能，同时推出可定制Firefly图像生成器。Perplexity Health：成立健康咨询委员会（含Dr. Eric Topol），Computer产品新增健康数据集成，连接可穿戴设备、实验室结果和医疗记录。

7 产品动态 新面孔

JetBrains Air 发布 · Claude Code 支持 Channel 推送 · Skild AI 工厂机器人落地

JetBrains Air（新面孔）：全新的Agent开发环境，让 Codex、Claude Agent、Gemini CLI 和 Junie 在独立任务循环中并行运行、互不干扰。Claude Code Channels：现在支持从MCP服务器向运行中的会话推送事件（如CI结果、聊天消息），可通过Telegram或Discord远程控制Claude会话。Skild AI（新面孔）：宣布与ABB Robotics和Universal Robots合作，在制造生产线上部署Skild Brain AI，标志着AI机器人从实验室走向工厂车间。
为什么这件事重要

开发工具领域正在发生根本性变革：JetBrains Air让多个AI Agent共存一个IDE——这不是"AI辅助编程"，而是"AI编程团队"。Claude Code Channels让AI可以在你不在场时自主响应外部事件——Agent的"自主性"又进了一步。Skild AI与ABB/Universal Robots的合作则说明：工厂机器人的AI化不再是概念，而是ABB这种工业巨头已经在做的事。

行业趋势与警示
8 行业趋势

Andrew Yang 预警"办公室的终结"：20-50% 白领岗位将被削减 · 2026 年已裁员 28 万人

前总统候选人 Andrew Yang 发表文章《办公室的终结》，预测 20-50% 的白领工作岗位将被削减（涉及美国7000万办公室职员），中层管理人员首当其冲。与此同时，2026年AI裁员追踪数据显示：160+家公司已裁员28万+人，平均每天3500人。Cloudflare CEO 预计到2027年网络上的机器人流量将超过人类流量。研究还发现AI使人类写作更平淡、个人声音减少50%。
为什么这件事重要

当每天3500人因AI相关原因失业时，AI不再只是技术话题——它是社会话题。Yang的"20-50%"预测虽然范围很宽，但方向已被实际裁员数据验证。同时，"AI让写作变平淡"的研究提出了一个更深层的问题：当AI能做大部分"知识工作"时，人类独特的创造性和个性是否也在同步被磨平？

9 融资

本周融资速览：Oasis Security 1.2 亿 · Deeptune 4300 万 · Parallel 2000 万

Oasis Security（Sequoia + Accel领投，1.2亿美元）：管理非人类身份（NHI）访问控制，专注于AI Agent的身份验证和权限管理——这是Agentic AI时代的"安全基础设施"。Deeptune（a16z领投，4300万A轮）：为AI Agent构建"训练健身房"，让Agent在模拟环境中学习和改进。Parallel（2000万美元）：用AI Agent自动化医院行政管理，瞄准美国医疗体系中占比30%的行政成本。
为什么这件事重要

三笔融资都指向同一个方向："AI Agent的基础设施"。Oasis解决Agent的身份和权限问题，Deeptune解决Agent的训练问题，Parallel展示Agent的实际落地场景。当Sequoia和a16z同时重注Agent基础设施时，说明Smart Money认为：2026年的真正机会不在模型本身，而在让模型"安全、可靠地做事"的基础设施层。
