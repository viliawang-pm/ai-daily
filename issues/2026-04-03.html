1 SIGNAL
Google Gemma 4 凌晨突袭发布——31B参数越级击败20倍体量竞品，Apache 2.0真开源
为什么重要：Google DeepMind在Cloud Next上正式发布Gemma 4开源模型家族（31B/12B/4B/2B），基于Gemini 3研究构建。31B版本在多项基准上超越Llama 3 70B，关键变化是从Google专有许可切换到Apache 2.0，真正允许商用。这意味着端侧AI和私有化部署的成本门槛再次大幅降低。

2 SIGNAL
阿里Qwen3.6-Plus发布——Code Arena全球第二，编程能力超越3倍参数竞品
为什么重要：4月2日发布的Qwen3.6-Plus在LMArena Code Arena排名全球第二，超越OpenAI、Google、xAI等国际巨头的编程模型。千问3.6编程能力是3.5的质变而非量变，涌现出极强的智能体编程能力。这是中国大模型在编程这一高价值赛道上首次站到全球前三。
来源：中新网、量子位、阿里云 · 原文链接
3 SIGNAL
商务部正式回应Meta收购Manus——"支持跨国合作但须依法履程"
为什么重要：4月2日商务部例行发布会上，发言人何亚东首次正式回应Meta收购中国AI Agent创企Manus事宜，明确"跨国经营需遵守中国法律"。Manus是全球最受关注的通用AI Agent产品之一，Meta的140亿美元收购案现处于中国监管审查阶段。这是中美AI产业链深度交织下，主权审查常态化的标志性事件。
来源：新华社、商务部、IT之家、快科技 · 原文链接

48小时5款大模型连发——Google/Meta/阿里/Anthropic同时开火，"模型核爆周"震动行业
为什么重要：4月2-3日的48小时内，Google发布Gemma 4、阿里发布Qwen3.6-Plus、Meta加速Llama 4开源推进、加上此前Anthropic的Claude Code泄露余波和OpenAI GPT-4o退役——五大巨头几乎同时甩出重磅动作。腾讯云开发者社区评论："2026年AI圈的卷法已经超出想象。"行业竞争从"参数比拼"转向"生态卡位"。

5 SIGNAL
OpenAI正式退役GPT-4o——4月3日后商业用户自定义GPT不再支持，全面转向GPT-5系列
为什么重要：GPT-4o曾是OpenAI最成功的多模态旗舰模型，其退役标志着OpenAI彻底进入GPT-5时代。对企业用户而言，意味着必须完成GPT-5系列迁移。同时OpenAI预告4月下旬春季发布会，GPT-5.5 Spud（代号"Spud"，预训练已完成）即将登场。
来源：OpenAI Help Docs、VPSSos

为什么重要：3月31日的Claude Code 51万行源码泄露事件在4月初持续升温。Inc.报道美国国会议员致函Anthropic，警告泄露可能"侵蚀美国AI优势"。一周内连续两次安全事故（先Mythos曝光，再源码泄露）使Anthropic的IPO叙事面临严峻考验。Zscaler已发现恶意软件利用泄露代码作诱饵。
